# DSM Marketing System (Gift Bot)

Система маркетингових акцій DSM: два Telegram-боти (продавці, спільнота) +
дві веб-панелі (адмінка, кабінет партнера). Технічне завдання — `SPEC.md`.

Проєкт розробляється автономним агентом за розкладом. Хто хоче зрозуміти
контекст і правила роботи — дивись `CLAUDE.md` (інструкція агенту),
`DECISIONS.md` (прийняті рішення), `ROADMAP.md` (план) і `PROGRESS.md`
(поточний стан).

## Локальний запуск

```
pip install -r requirements.txt
cp .env.example .env   # заповнити токени
pytest
```
