# ТЗ на систему маркетингових акцій DSM

> Перенесено з `ТЗ_на_систему_маркетингових_акцій_DSM_1.docx` без змін по суті, лише у markdown для читання агентом.

## 1. Мета проєкту

Створити єдину систему для проведення маркетингових акцій DSM, яка дозволить:
- проводити всеукраїнські та локальні акції;
- автоматизувати реєстрацію продажів продукції DSM;
- мотивувати продавців;
- мотивувати партнерські мережі;
- проводити розіграші серед покупців;
- отримувати статистику та аналітику;
- інформувати аудиторію про новинки, акції та результати.

## 2. Архітектура системи

### 2.1 DSM Promo Bot
Telegram-бот для продавців. Призначення: реєстрація продажів, статистика продавців, рейтинги, участь в акціях, мотиваційні програми.

### 2.2 DSM Community Bot
Telegram-бот для покупців та спільноти. Призначення: інформування про акції, новини та новинки продукції, результати розіграшів, FAQ, робота в Telegram-групах, функції модерації (за потреби).

### 2.3 DSM Admin Panel
Єдина веб-панель управління всією системою. Через неї DSM керує: акціями, продуктовими лініями, призами, партнерськими мережами, статистикою, результатами розіграшів.

### 2.4 Partner Cabinet
Кабінет представника партнерської мережі. Через нього партнер: додає продавців, відключає продавців, переглядає статистику, контролює результати своєї мережі.

## 3. Учасники системи

- **DSM** — організатор акцій, повний доступ до всіх функцій.
- **Партнерська мережа** — бере участь у маркетингових акціях DSM, бачить лише власні результати.
- **Продавець** — реєструє продажі через DSM Promo Bot, прив'язується до мережі, а не до конкретного магазину.
- **Покупець** — купує продукцію DSM та бере участь у розіграшах.

## 4. Продуктові лінійки

DSM повинна мати можливість створювати необмежену кількість продуктових лінійок (напр. DSM Tea, нові лінійки, сезонні продукти, спеціальні серії). Для кожної лінійки: назва, опис, статус активності.

## 5. Налаштування акцій

При створенні акції DSM обирає: одну лінійку, декілька лінійок, або усю продукцію DSM. Продавець у боті бачить перелік лінійок, які беруть участь у поточній акції.

## 6. Керування продавцями

Кожен продавець закріплюється за партнерською мережею. Керування виконує представник мережі: запросити, активувати, деактивувати продавця, переглядати статистику й рейтинг. DSM вручну продавців не додає.

## 7. Реєстрація продажу

Через DSM Promo Bot продавець вносить: номер телефону покупця, продуктову лінійку, кількість проданої продукції. Додатково — ім'я покупця. Фото чеків не використовуються. Інтеграції з касовими апаратами у v1 немає.

## 8. Участь покупців у розіграші

Покупці отримують шанси відповідно до правил конкретної акції (напр. 1 одиниця = 1 шанс). Правила налаштовуються окремо для кожної кампанії. Один покупець може здійснювати необмежену кількість покупок; кожна покупка додає нові шанси. Обмежень по номеру телефону немає.

## 9. Рейтинг продавців

Автоматичний рейтинг. Продавець бачить: кількість продажів, кількість проданої продукції, місце в мережі, місце по акції серед усіх.

## 10. Механіки мотивації продавців

Налаштовуються DSM окремо для кожної акції:
1. **Фіксована винагорода** — напр. 1 одиниця = 5 грн.
2. **Градація винагород** — напр. до 50 од. — 3 грн, 51–100 — 7 грн, 100+ — 20 грн.
3. **Призи за рейтингом** — ТОП-1, ТОП-2, ТОП-3, ТОП-10.
4. **Комбінована схема** — поєднання виплат, бонусів, рейтингів, призів.

## 11. Мотивація партнерських мереж

Система дозволяє оцінювати приріст продажів партнерської мережі (напр. травень 100 000 грн → червень 150 000 грн → приріст 50 000 грн). DSM може використовувати показник для нарахування бонусів.

## 12. Контроль достовірності продажів

У v1 немає: чеків, касових інтеграцій, SMS-підтверджень, ручної перевірки кожного продажу. Контроль — через порівняння статистики зареєстрованих продажів та обсягу закупівель мережі. При розбіжностях DSM може запросити пояснення у партнера.

## 13. Контроль підозрілої активності

Автоматичне відстеження аномалій. Базове правило: понад 20 продажів від одного продавця за добу → сповіщення DSM та представнику мережі. Поріг налаштовується.

## 14. DSM Community Bot — функції

Інформування про акції та новинки, публікація результатів розіграшів, FAQ, навігація по ресурсах DSM, робота в Telegram-групах, модерація (за потреби).

## 15. Призи

Будь-які типи: подарункові набори, техніка, сертифікати, тур. путівки, грошові винагороди, спеціальні подарунки, інше. Призначаються покупцям, продавцям, партнерським мережам.

## 16. Проведення розіграшу

Після завершення акції DSM запускає розіграш через адмін-панель. Система автоматично: формує список учасників, враховує кількість шансів, визначає переможців, формує підсумковий звіт, зберігає результати.

## 17. Звіти

Статистика продажів, по продуктових лінійках, по акціях, рейтинг продавців, рейтинг партнерських мереж, результати розіграшів, список переможців.

## 18. Майбутній розвиток (поза v1)

SMS-повідомлення покупцям, особистий кабінет покупця, AI-аналіз активності продавців, додаткові механізми перевірки продажів, інтеграції з внутрішніми системами DSM, розширена аналітика.

## Відкриті питання ТЗ (не погоджені замовником)

2. Де публікуються результати розіграшів: канал / група / окрема сторінка / усі варіанти?
3. Яку механіку мотивації продавців використовуємо для першої акції?
4. За яким показником оцінюється приріст партнерської мережі: сума закупівель / кількість продукції / комбінований?
